# イルカの上海 〜通信工事するイルカ〜

広告なし・登録なしで遊べる麻雀ソリティア（上海）です。ブラウザだけで動き、一度開けばオフラインでも遊べます。

▶ **遊ぶ：** https://o52dagaya-maker.github.io/iruka-shanghai/

## iPhone でアプリのように使う
1. 上のURLを **Safari** で開く
2. 共有ボタン（□に↑）→「ホーム画面に追加」→「追加」
3. ホーム画面のイルカのアイコンから起動すると全画面で遊べます

Android は Chrome で開いて「ホーム画面に追加」（またはインストール）でも使えます。

## 主な機能
- 8 種類の盤面（小舟〜亀）、すべて必ず解ける配牌
- スロット（4つ）に牌を置いておける／磁石／ヒント／もどす／まぜる
- 🔍 拡大（牌が小さい盤は自動で拡大、指でなぞって移動）
- ⏸ 一時停止（タイマー停止・盤面を隠す、バックグラウンドで自動停止）
- 🎷 BGM は 1940 年代ジャズラウンジ風のオリジナル 4 曲（ブラウザ内で合成、音声ファイルなし）。iPhone のマナーモードでも鳴ります。メニューで ON/OFF・音量（v1.6.2: Androidアプリ版でBGMが止まったままになる問題を修正。バージョン表示を5回タップで診断情報）
- 上海IQ と自分ランキング（記録はこの端末の中だけ）

## プライバシー
広告・解析・外部通信はありません。セーブデータは端末のブラウザ内（localStorage）にのみ保存されます。

マスコットのイルカのイラストは作者の著作物です。
